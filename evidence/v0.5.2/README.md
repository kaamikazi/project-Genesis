## Reproduce

```
python tools/generate_evidence_m5c.py
```

This needs a fresh `evidence/v0.5.2`; the freeze step refuses to overwrite an existing protocol. Sealed-4 is drawn from the OS at freeze, so a re-run produces a different final-case set and its own commitment. The published manifest here is the one that was used.

## What these results do and do not show

They cover 12 of 45 combinations of one finite task family, with one controller realisation per combination and preserved knowledge only. Within-world units are not replicates. The paired rule is descriptive.
