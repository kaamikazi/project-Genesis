# Evidence v0.6.1 (M6a: Gemini adapter)

Generated by `python tools/generate_evidence_m6a.py` from runtime commit `ed3f5a7`. `runs.json` records source fingerprints at start and end, per-step exit codes and `live_inference_calls: 0`.

**Everything here is credential-free and offline.** Gemini-shaped responses come from a scripted fixture (`GeminiFixtureResponder`), served in-process or by a loopback server that speaks the `generateContent` wire format. The key is a synthetic value set inside the generator process; `runs.json` checks that even that value appears nowhere in the evidence. **No request was sent to Google.** Fixture responses say nothing about how a real model behaves.

## Fault matrix (one decision each)

| Case | Outcome |
|---|---|
| normal, thought parts | Proposal parsed and applied; thought text dropped, never stored |
| invalid JSON, extra field, empty text | One repair, then the repaired answer was used (2 requests) |
| illegal action | Parsed; rejected by the engine like any other controller's action |
| blocked prompt, no candidates, two candidates, safety stop, `MAX_TOKENS`, non-text part | Recorded with the reason; labelled fallback; no repair (1 request) |
| missing, inconsistent or non-finite usage | Proposal used; charged at the larger of report and reservation |
| usage above the reservation | Proposal used; `reservation_exceeded` recorded and dispatch stopped for the run |
| credential-like text in the response | Scrubbed, not parsed, fallback |
| HTTP 500, HTTP 400 (schema not supported) | `failed-delivered` (definite rejection, reservation kept), fallback |
| HTTP 429 | `failed-delivered`; every later request blocked with "quota or rate limit reached … no retry" |
| redirect (302) | Refused, not followed; the redirect target received nothing |
| timeout | `outcome-unknown`, reservation kept, not resent |

In every case the synthetic key arrived only as the `x-goog-api-key` header, and neither the key nor thought text appears in the ledger, tick records, run rows or export.
