# Evidence v0.5.1 (M5b)

Generated by `python tools/generate_evidence_m5b.py` from runtime commit `1e7dcad`. The tree was clean at both the start and the end; see `runs.json`. All 21 steps exited 0.

After generation, a reporting fix (`e20e84e`) made the reducer keep the creation-attributed freeze fields, and the summaries now read freeze records from the exported state. Only the `summaries` step was re-run from that commit (`runs.json` records it). Runs, exports and sealed scores are unaffected.

The `*.reducer.json` files written during generation contain freeze copies without `created_upto_best`. The authoritative values are in the exports.

Everything ran offline with designed controllers; no model calls were made.

## Caveat: duplicate worlds

Every world uses the same controller seed, and hidden world parameters have only 45 combinations. Seeds 221 and 222 share hidden parameters, and so do 225 and 226. They produced identical invention outcomes, so the six evaluation seeds are four distinct worlds for invention measures.

The frozen comparisons are reported as frozen. `summary.json` adds a labelled post-hoc analysis over the four distinct worlds.

Teaching interactions differ between duplicate seeds, because terrain affects movement. Calibration seeds 310 and 311 also share parameters with each other, and with v0.5.0 calibration seed 300.
