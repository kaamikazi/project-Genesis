# Vision

**Can a society of persistent artificial agents accumulate, preserve and improve useful capabilities through interaction, invention and knowledge transmission?**

GENESIS is meant to grow into a long-running world where inhabitants with limited views and persistent histories gather, trade, build tools that measurably work, teach each other, form institutions, and pass knowledge to later generations. Every such claim should be backed by a world transition, an artifact or a measurement you can inspect.

## The principles that do not change

- **Evidence over narrative.** A statement, a belief, an attempted action, an accepted action, an observed outcome, a verified artifact and an analyst's interpretation are different things, and the system keeps them apart.
- **Mechanical authority.** One engine owns the world. Controllers only propose.
- **No secret omniscience.** Controllers see restricted, local observations.
- **Honest experiments.** Every attempt is recorded, including failed ones, and nothing is cherry-picked.
- **No inflated language.** GENESIS does not claim consciousness, AGI, biological evolution or emergence. Changes to stored memory and skills are kept distinct from changes to model weights. No weights change at all.

## Where it stands (v0.3.0)

An audited foundation runs fully offline on a laptop:

- two settlements and 8 inhabitants, validated at 20
- conserved resources and usable communal storage
- a bounded program language with an independent evaluator, aggregate-only agent feedback, and verified revisions
- library-based transmission, where knowledge access is a capability
- **retirement and fresh successors**, with typed inheritance packages
- a **controlled succession experiment** (matched forks from one checkpoint, with a physical-parity check) showing successors acquiring and using inherited procedures only through the permitted path
- an **independent event reducer** behind every reported number
- transactional persistence with replay, labelled forks and export
- a visual observatory with retention evidence chains

**What it is not yet:** a civilization. The inhabitants follow designed rules, the "invention" is a hill-climb in a 16-program space that reaches its optimum within about 20 ticks, succession is scheduled by the scenario, and social behaviour is scripted. Nothing has emerged. [IMPLEMENTATION_STATUS](IMPLEMENTATION_STATUS.md) lists exactly what exists.

## The road from here

[ROADMAP](ROADMAP.md) sets out the dependency order:

1. Teaching with real costs.
2. One LLM controller under strict budgets.
3. Settlement institutions.
4. Richer invention, with problems that cannot be solved in one lifetime, so that inheritance can become cumulative.
5. More settlements and longer worlds.
6. Human visitors acting through the same validated contracts.
7. Generalisation across unfamiliar worlds.

The long-term ambition stays enormous: a world in which useful knowledge accumulates beyond any one inhabitant's lifetime, with proof.
